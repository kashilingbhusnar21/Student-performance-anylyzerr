# 📘 Overview

This project analyzes student performance and provides insights using data visualization and interactive dashboards.

It helps to:

* Calculate student averages and grades
* Identify top and lowest performers
* Analyze subject-wise performance
* Compare students using charts

---

# 🚀 Features

### ✔️ Automatic Calculations

* Student average score
* Grade assignment (A–F)
* Top and lowest performer

### ✔️ Data Visualization

* Subject-wise average chart
* Top 10 students
* Grade distribution (pie chart)
* Student comparison graphs

### ✔️ Interactive Dashboard

* Student profile view
* Compare two students
* Compare multiple students
* Download processed CSV
